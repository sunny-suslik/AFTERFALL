# AFTERFALL — Development Roadmap

This roadmap is provisional. It describes a sensible order of work, not promised release dates.

## Phase 0 — Project foundation
- Create the Unreal Engine 5 C++ project
- Set up source control and repository conventions
- Establish coding standards and a basic module structure
- Build and run an empty project successfully

## Phase 1 — First playable prototype
- Implement a basic player character and camera
- Add movement and a simple interaction system
- Create a small test environment
- Validate performance on the available development hardware

## Phase 2 — Core survival loop
- Add inventory and item definitions
- Add resource gathering
- Add basic crafting
- Prototype essential survival mechanics
- Add save/load for the prototype

## Phase 3 — World and content foundations
- Test World Partition and world streaming
- Create a small representative outdoor region
- Prototype one abandoned location and one shelter
- Add basic NPC interaction
- Measure memory, CPU, and GPU costs

## Phase 4 — Controlled expansion
- Expand locations and environmental variety based on measured performance
- Improve AI, crafting, building, and progression
- Evaluate vehicles and larger-scale world simulation
- Reassess the long-term 200 × 200 km ambition against technical results

## Scope rule
Do not build the full world before the small prototype proves that the main gameplay loop and streaming approach are viable.

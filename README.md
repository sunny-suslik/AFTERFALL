# AFTERFALL

**AFTERFALL** — постапокалиптическая survival-игра с открытым миром.

> Разработка временно ведётся на **Godot 4 + GDScript**, без необходимости устанавливать Unreal Engine 5. Архитектуру и игровые данные стараемся делать переносимыми, чтобы в будущем при необходимости можно было сменить движок.

## Концепция

- Открытый мир с целевым масштабом около 200 × 200 км.
- События происходят после ядерной войны Европы и NSSSR.
- Исследование мира, выживание и развитие собственного поселения.
- NPC с потребностями, распорядком и ролями.
- Фракции, экономика, задания и динамические события.
- Транспорт, убежища и строительство.
- Камера от первого и третьего лица.

## Технологии

- Godot 4.x
- GDScript
- JSON для игровых данных
- Git и GitHub для контроля версий
- Blender для 3D-моделей (позже)

## Быстрый запуск

1. Установить Godot 4.x с официального сайта: https://godotengine.org/download/
2. Скачать или клонировать репозиторий.
3. В Godot выбрать **Import** и указать файл `project.godot`.
4. Запустить проект клавишей F6/F5 или кнопкой Play.

## Управление прототипом

- WASD — движение
- Мышь — поворот камеры
- Space — прыжок
- Shift — бег
- C — переключение вида от первого/третьего лица
- Esc — освобождение/захват мыши

## Текущий статус

**Prototype 0.1 — Foundation.** Сейчас это стартовая техническая основа: тестовая сцена, базовый персонаж, камера и документация. Это ещё не полноценная игра; механики будут добавляться постепенно.

## Структура

- `scenes/` — игровые сцены
- `scripts/` — логика игры
- `data/` — данные предметов и локаций
- `docs/` — дизайн и техническая документация
- `assets/` — будущие модели, текстуры и звук

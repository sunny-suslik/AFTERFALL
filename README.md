# AFTERFALL

**AFTERFALL** is a planned 3D open-world survival game developed with **Unreal Engine 5** and **C++**.

## Project status

**Concept / pre-production.** The repository currently contains project documentation and setup files. Gameplay systems, maps, assets, and a playable build have not been implemented yet.

## Setting

The game is set on Earth one year after a global nuclear catastrophe. The world is envisioned as a dangerous, partially abandoned environment with ruined cities, bunkers, settlements, and wilderness.

## Long-term vision

- Explore abandoned locations and a large open world
- Scavenge resources and manage survival needs
- Craft equipment and build shelters
- Encounter NPCs and settlements
- Eventually use transport and explore a much larger world

A world size of approximately **200 × 200 km** is a long-term ambition only. It must be validated through prototypes, streaming tests, and performance measurements before it can be treated as a feasible target.

## Technology

- **Engine:** Unreal Engine 5
- **Gameplay programming:** C++
- **Blueprints:** no Blueprint gameplay implementation planned

## Development approach

Start with a small C++ prototype, validate the core gameplay loop, and expand only after performance and architecture have been tested.

# AFTERFALL

**AFTERFALL** — постапокалиптическая survival-игра с открытым миром.

> Текущая разработка ведётся на **Godot 4 + GDScript**, без необходимости устанавливать Unreal Engine 5. Данные и игровые правила проектируются так, чтобы по возможности не зависеть от конкретного движка.

## Концепция

- Открытый мир с целевым масштабом около 200 × 200 км.
- События происходят после ядерной войны Европы и NSSSR.
- Исследование мира, выживание и развитие собственного поселения.
- NPC с потребностями, распорядком и ролями.
- Фракции, экономика, задания и динамические события.
- Транспорт, убежища и строительство.
- Камера от первого и третьего лица.

## Технологии

- Godot 4.x
- GDScript
- JSON для игровых данных
- Git и GitHub для контроля версий
- Blender для 3D-моделей (позже)

## Быстрый запуск

1. Установить стабильную версию Godot 4.x.
2. Скачать или клонировать репозиторий.
3. В Godot выбрать **Import** и указать файл `project.godot`.
4. Запустить проект клавишей F6/F5 или кнопкой Play.

## Управление текущим прототипом

- WASD — движение
- Мышь — поворот камеры
- Space — прыжок
- Shift — бег
- C — переключение вида от первого/третьего лица
- Esc — освобождение/захват мыши

## Текущий статус

**Prototype 0.1 — Foundation.**

В репозитории есть тестовая сцена, базовый контроллер персонажа, документация и первые независимые заготовки систем характеристик, инвентаря, взаимодействий, сохранений и настроек.

Важно: наличие заготовки системы не означает, что она уже подключена к игровому процессу. Следующая задача — интегрировать эти модули в один проверяемый вертикальный срез.

## Структура

- `scenes/` — игровые сцены
- `scripts/player/` — контроллер и характеристики игрока
- `scripts/inventory/` — модель инвентаря и стопки предметов
- `scripts/world/` — взаимодействия с объектами мира
- `scripts/systems/` — сервисы сохранения и настроек
- `data/` — JSON-данные предметов, регионов и параметров игрока
- `docs/` — дизайн, архитектура, настройка среды и статус систем
- `assets/` — будущие модели, текстуры и звук

## Разработка на устройствах

- **Windows:** основная работа в редакторе Godot, запуск и тестирование.
- **Android:** просмотр и небольшие правки кода, JSON и документации; полноценное тестирование 3D и сборка выполняются на Windows.

Подробности: [docs/development_setup.md](docs/development_setup.md).

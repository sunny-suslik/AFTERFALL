# AFTERFALL — рабочая среда

## Основной стек

- Godot 4.x — основной движок прототипа.
- GDScript — игровая логика.
- JSON — переносимые описания контента и начальных параметров.
- Git + GitHub — контроль версий.
- Blender — будущие модели и окружение.

## Windows

1. Установить актуальную стабильную версию Godot 4.x.
2. Скачать репозиторий или выполнить `git clone`.
3. В Project Manager нажать Import и выбрать `project.godot`.
4. Открыть проект и запустить главную сцену клавишей F6/F5.

## Android

Телефон используем для чтения и небольших правок GDScript, JSON и Markdown через GitHub или редактор кода. Полноценное тестирование 3D-сцен и сборку пока выполняем на Windows.

## Правила работы

- Перед крупными изменениями создавать отдельную ветку.
- Не хранить пароли, токены и личные данные в репозитории.
- Не коммитить папку `.godot/` и экспортированные сборки.
- После изменения сцены или скриптов запускать проект в Godot.
- Не отмечать задачу выполненной, пока она не проверена.

## Текущие ограничения

Это ранний технический прототип. Системы в папках `scripts/` — заготовки для дальнейшей интеграции; наличие файла не означает, что функция уже подключена к игровому процессу.
